
# ✨ Digital Particle Universe

An interactive visual universe made of glowing digital particles. Move your cursor or touch the screen to explore a colorful animated particle field.

## Features

- Animated glowing particles and background stars
- Mouse and touchscreen interaction
- Adjustable particle density
- Adjustable animation speed
- Five cosmic color themes
- Toggleable particle connections
- Cosmic Burst effect
- Reset control
- Responsive mobile-friendly design
- No external libraries or API keys required

## Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML Canvas API

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Deploy with GitHub Pages

1. Open the repository on GitHub.
2. Go to Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Choose the `main` branch and `/ (root)` folder.
5. Click Save and open the published website.

## Project Structure

- `index.html` — webpage structure and controls
- `style.css` — neon design and responsive layout
- `script.js` — particle animation and interactions
- `README.md` — project documentation

## Learning Objectives

This project demonstrates canvas rendering, animation loops, particle motion, pointer events, and interactive user interface controls.

## Note

This is a creative particle visualization, not a machine-learning model.
